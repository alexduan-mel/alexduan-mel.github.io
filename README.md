# alexduan-mel.github.io

Personal site powered by Hugo and PaperMod.

Homepage: https://alexduan-mel.github.io/

## Local development

```bash
hugo server
```

## Theme (git submodule)

```bash
git submodule update --init --recursive
```

## Deploy

GitHub Pages deploys via `.github/workflows/pages.yml` on every push to `main`.
